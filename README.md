## 📖 About

**Cium** (*"For Sayang 💕"*) is an affectionate, handcrafted web sanctuary celebrating over **671+ days** of love, companionship, and shared memories. 

Designed with a cozy retro-pastel aesthetic inspired by vintage pixel art and scrapbook journals, the application provides an intimate, interactive experience. It features a live relationship clock, confidential digital love letters, an embedded background jukebox player, and interactive polaroid memories.

---

## ✨ Features

- ⏳ **Real-Time Relationship Milestone Tracker**: Dynamically calculates days, hours, minutes, and seconds spent together from the very start.
- 💌 **Interactive Digital Love Letters**: Sealed envelopes that unfold heartfelt notes (*"Surat untuk Sayang 💌"*) with smooth open/close animations.
- 🎵 **Curated Embedded Jukebox**: An in-browser music player loaded with 5 meaningful audio tracks, complete with playlist controls (play, pause, next, previous).
- 📸 **Photo Memories & Polaroids**: Curated photo cards, video call screenshots, and commemorative moments captured with warm vintage frames.
- 🌸 **Delightful Micro-Interactions**: Custom easter egg buttons (*"Kangen? 🥺"*, *"BUKA"*), floating hearts, and soft soundscapes.
- 📱 **Mobile-First Responsive Layout**: Optimized with fluid viewport scaling for phones and touchscreens.

## 🚀 Quick Start

To view or host the website locally:

```bash
# 1. Clone the repository
git clone https://github.com/kecrwn/Cium.git

# 2. Enter project directory
cd Cium

# 3. Open in your default browser
# macOS:
open index.html
# Linux:
xdg-open index.html
# Windows:
start index.html
```

Or serve with any static HTTP server:
```bash
npx serve .
# or
python3 -m http.server 8080
```
